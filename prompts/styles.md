# What this studio has already made (inspiration — and a list of things NOT to repeat verbatim)

Distilled from ~90 hand-built Remotion films. Use them to understand the range and the quality bar; then invent
something new for THIS story. Never rebuild one of these 1:1 — if a film's world sounds like one below, change the
metaphor, the camera language AND the type.

## Motion-UI (app remakes) — the client's favourite family
- Hermes desktop UI floating in one 3D space; single continuous camera glides between vector remakes of panels,
  cursor clicks and typing, kinetic headlines with backplates; panels converge into the logo at the end.
- PRO PLAN dashboard: light dashboard + dark app remakes, AE-style camera, zoom punches on keywords, no voice.
- Behind-the-scenes: the making-of replayed as a screen recording of a chat app — zoom on typing, blur on everything
  except the focused message, live "thinking" rows, tool rows with spinners → ✓, progress bars.
- Claude Code tutorial: macOS desktop, browser dashboard + VS Code-style editor typing a settings file, step badges.
- Windows 11 + Chrome tutorial: realistic desktop, taskbar, omnibox typing, download bubble, installer windows.
- Phone screens remade from screenshots (wallet app): screenshot-accurate base + patched values, damped camera pan.
- iPhone chat thread as the whole video (DM intro): lock-screen notification opens a chat, each message pops into a
  kinetic graphic.
- Refusal → switch model: chat UI where a refusal bubble triggers a model dropdown and a new answer.

## Editorial / print
- Swiss price poster: paper canvas, bordered numbered panels, red route line, slash-cut prices, HEMAT stamps,
  pull-out overview of the whole poster.
- Notice board ("lembar pengumuman"): lined paper sheet, archive holes, colour wash, browser + terminal "proof"
  frames pinned to the sheet. Client favourite for news/explainers.
- Zine / workshop notebook: bright paper, black ink, highlighter hot-words, stickers, stamps, graph paper.
- AU scrapbook: pastel paper, washi tape, self-drawing doodles (handwriting font), sticker cards.
- Risograph-ish brand film: static print grain, tone-on-tone camo blobs, long soft settles (no bounce).
- Financial ledger / receipt paper that breaks into alarm red at the reveal.
- Mission-control spec sheet: pitch black, monochrome, technical labels, one accent.

## Kinetic / billboard
- Boba-style text-led intro: fast kinetic headlines, bold numbers, colour fields.
- Glyph-by-glyph mask wipe + 3D tilt + overshoot + motion-blur smear that resolves (and animated exits).
- Aggressive slams: tight per-letter entry, big overshoot, stage shake, a split-second chromatic split.
- Billboard stage: gradient stage, gooey morph transitions, kinetic type with motion-blur trails, hero numbers.
- Giant-type LP vlog: bright billboard, huge type, fast beats (nothing static > 2 s).
- Proclamation poster: full red field, sunburst rays, red-white-gold confetti, flat FlagWipe transitions.

## Worlds / metaphors
- Sunrise ascent: camera climbs a peach-dawn → noon sky, far parallax sun, glass cards between clouds.
- Graphite fly-through: off-white 3D studio, dark UI cards, perspective floor, particles, depth of field.
- Night market: side-scrolling 2D cartoon, each stall = a model, menu boards with prices.
- Train: side-scrolling, mascot conductor, each carriage = a winner.
- Hologram room → "token world" inside a phone panel (nested-world camera), robot narrator, quota jar.
- Pixar-ish 2.5D character skit (soft gradients, AO shapes, lamp key + moon rim).
- GTA-style game HUD layered over a 3D render (minimap, wanted stars, objective banner).
- Cosmos / orbital particles / light rays (Aether); particle streams on bezier paths (Streamflow).
- Trailer beats (darkness → charge → grid run → shatter).
- Blender product renders with call-outs pinned to 3D anchors.

## Techniques that made those films good (reuse the IDEAS, not the code)
- One continuous camera / one world; information changes by morphing in place, camera moves, or in-world
  metaphors. Swapping discrete scenes (slide out → slide in) reads as AI slop to this client.
- Depth-of-field focus: sharp = what the narration is explaining right now; everything else blurred, dimmed and
  desaturated; the camera aims at the focus.
- Every spoken keyword gets a visual event on its word (cue), plus a small zoom punch.
- Measured text (never estimate widths); pills sized to their text; nothing touches a card or frame edge.
- Transitions without slides: flat solid-colour wipes (FlagWipe), zoom-through a shape, iris, morphs of a shape
  that already exists in the frame, whip-pans inside one world.
- Portrait: content sits low-middle (avoid big empty bands under it); captions live in the bottom band.
- Price stories: official price struck, ours rolls in (odometer), savings badge stamps, fine print with sources/FX.
- Pixel-accurate UI remakes when the product UI is shown: real proportions, sampled colours, no invented menu items.

## Things the client rejected
- Abstract particle-morph "motion" with no UI or story ("jelek… maunya dynamic UI motion").
- Dark theme when the brand is light (match the brand's own visual language).
- Same template / same components across videos ("kayak template", "itu-itu aja").
- Slide-deck transitions, text colliding with edges ("nabrak"), metaball wipes that leak text.
